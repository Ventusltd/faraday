Faraday

A numbered, dated log of what was actually done and what was actually observed. Failures are recorded, because an experiment that showed nothing is a result. Numbers run continuously and are never reused.

The method.
  1. Number continuously. An experiment keeps its number forever, so anything can cite anything by number alone.
  2. Date it. A measurement without a time is not a measurement.
  3. Say what was asked before saying what was found.
  4. Record the apparatus: the command, the machine, the version. Someone must be able to repeat it.
  5. Quote what was observed, verbatim where possible, before interpreting it.
  6. Record NO EFFECT and REFUTED as readily as CONFIRMED. Faraday's null results are half the value of his notebooks.
  7. Name the law it tests, or say that it tests none yet.

2 · The timer measured how fast commands were queued, not how much was drawn

The question

Apparatus

Same page and machine. Arithmetic, then a GPU fence.

What was done

What was observed
37,796,045,093 in 0.8 s is 47 billion points per second. Repeating the run gave 9.7 s, then 34.0 s, for the same work, which is not how a fixed amount of drawing behaves.

16 · Eight dots add one and one

2026-09-19 · tests L26 · CONFIRMED

The question

Can the dots compute anything at all, or can they only be lit? The claim under test was made the same evening: every dot can be programmed like a transistor.

Apparatus

A cell is one dot with a permanent key and no other property. It is dark or lit. A program gives each cell one rule, and there are only two kinds: an input cell is lit when the visitor says so; a gate cell is lit UNLESS both of the two cells it answers to were lit one tick earlier. That second rule is the gate from which every other logic gate can be made. Nothing is stored per cell: the state of a cell at a tick is worked out backwards from that tick to tick nought, when every gate cell is dark.

What was done

Wrote a half adder as a program of 8 cells (2 inputs, 6 gate cells, one kind of gate only). Ran all four input rows. The check reads the lit or dark state of the sum cell and the carry cell after they settle; it never looks at the wiring. Ran it again with the cache switched off, so nothing at all is kept between one question and the next. Then planted a fault (the carry cell rewired) and ran the same check.

What was observed
Rows as read from the cells: 0 and 0 give sum 0 carry 0; 0 and 1 give sum 1 carry 0; 1 and 0 give sum 1 carry 0; 1 and 1 give sum 0 carry 1. Identical with the cache off. The slowest row settled at tick 3. The planted fault was caught.
What it shows

A cell whose rule answers to the OUTPUT of other cells is a logic gate, and cells so wired compute. One and one make two, read off the dots. The word that was honest before this entry was 'programmable'. After it, for this apparatus, 'computes' is also honest. It is a statement about cells run by this rule. It is not a statement that any published page computes anything.

19 · Two dots remember, with nothing stored in either

2026-09-19 · tests L26 · CONFIRMED

The question

A working view earlier the same evening was: the day a latch is wanted, one bit must be kept per dot, and 'nothing stored per dot' must be dropped. Is that so?

Apparatus

Two gate cells, each answering to the other, and two input cells (set and reset, where OFF means 'do it'). Same two rules as entry 16. Still nothing stored per cell.

What was done

Held reset for ticks 0 to 5. Gave a three tick set pulse at ticks 10 to 13. Left both inputs idle and read the output cell 26 ticks later. Gave a reset pulse at ticks 40 to 43 and read again. Separately: never reset it, and read it for eight ticks. Separately: counted how many questions the backwards working asks for tick 12 and for tick 24 with the cache off.

What was observed
After reset: 0. During set: 1. Twenty six ticks after the set pulse ended: 1. After the second reset: 0. Never reset: 10101010, lit and dark in turn for ever. Questions asked: 25 for tick 12, 49 for tick 24.
What it shows

The earlier view was wrong and is corrected here. The latch remembers, and neither cell stores anything: the memory is in the HISTORY OF THE INPUTS, which is part of the program, and the state at any tick is recomputed from it. What remembering costs is time, not storage: the work grows with the tick asked for. A real page would keep a frame to save that time; that is a cache and can be thrown away and rebuilt, which a stored bit cannot. Also recorded because it is true: a latch that is never reset does not settle, it flickers. A memory must be started in a known state, in cells as in silicon.
